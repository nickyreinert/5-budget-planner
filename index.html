Manche Ausgaben tauchen zweimal auf, weil zwei Konten dieselbe Bewegung zeigen (z. B. ein PayPal-Kauf und danach der Bank-Einzug, mit dem PayPal genau diesen Betrag einzieht). Oder SETTING-JSON einfügen

Alles außer dem SETTING: importierte Buchungen, manuelle Einträge, Kategorie-Korrekturen und sonstige Überschreibungen - als eigene Datei, um z. B. in einen anderen Browser umzuziehen (ohne Google-Konto/Cloud, siehe Tab "Sync").

Unklassifizierte Ausgaben (aktuell gewählter Jahresfilter) als kompakte, nach Summe sortierte Händlerliste + aktuellem Regelwerk + fertigem Prompt exportieren — die Datei kann direkt einem LLM gegeben werden, das ein erweitertes SETTING zurückgibt (oben importierbar).

Alternativ: Rohe CSV-Datei direkt an ein LLM anhängen. Dieser Beispiel-Prompt bittet es, ein importierbares SETTING-JSON zurückzugeben.

Sichere dein SETTING (und optional deine Transaktionsdaten) in der Cloud und nutze es auf mehreren Geräten - einfach mit deinem Google-Konto anmelden.

Zusätzlich zum SETTING auch importierte Buchungen, manuelle Einträge und Kategorie-Zuordnungen synchronisieren.
